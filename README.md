# Flowchart Multi-threading Tool 

Програмний інструмент для візуального моделювання, трансляції та тестування багатопотокових алгоритмів. 

##  Опис проєкту
Цей додаток дозволяє користувачу створювати блок-схеми для декількох потоків, які працюють зі спільною пам'яттю. Проєкт розроблений для демонстрації концепцій багатопотоковості, стану гонитви (race conditions) та недетермінованості систем.

##  Функціональні можливості
- **Графічний редактор:** Створення до 100 потоків, кожен з яких може містити до 100 блоків.
- **Спільна пам'ять:** Підтримка 100 цілочисельних змінних ($V_0..V_{99}$), доступних усім потокам одночасно.
- **Трансляція (Пункт 2):** Автоматична генерація чистого Python-коду на основі побудованих блок-схем.
- **Стрес-тестування (Пункт 3):** Аналіз недетермінованості шляхом багаторазового запуску симуляції та фіксації різних станів пам'яті.

##  Як користуватися
1. **Додати потік:** Створіть новий потік за допомогою відповідної кнопки.
2. **Додати блоки:** Використовуйте кнопку `+ Блок` для додавання команд:
   - `V=C`: Присвоєння константи змінній.
   - `PRINT`: Виведення значення змінної в консоль.
   - `IF`: Умовне розгалуження (якщо $V < C$, перехід на вказаний ID).
3. **Запустити:** Натисніть "Запустити все", щоб побачити виконання в реальному часі.
4. **Генерувати:** Створіть файл `generated_code.py` для автономного запуску алгоритму.

##  Технології
- **Мова:** Python 3.14
- **Бібліотека GUI:** Tkinter
- **Багатопотоковість:** Модуль `threading`
